## Scene Editor
The entry file for the program is `main.cpp`.
To run the program, press the Run/Debug in Visual Studio
### Loading
1. To Load, go to File > Open.
2. Select a .level file in the file browser
3. Press Ok
### Saving
1. To Save, go to File > Save or File Save As
2. Select the directory where you want the file to be saved
3. Place a file name

## Unity
### Loading
1. To Load, go to Tools > Level Loader > Browse File
2. Select the .level file you want to load
3. Press Load Level
### Saving
1. To Save, go to Tools > Level Exporter > Select File Path
2. Go to the directory where you want the file to be saved
3. Place a file name

## Unreal
### Loading
1. Navigate to the Content Browser and write click on LevelLoaderWidget
2. Select Run Editor Utility Widget
3. Copy and paste the file path (on the editable text box above load level button) to the .level file you want to load (Remove quotation marks if there are any)
4. Press Load Level
### Saving
1. Navigate to the Content Browser and write click on LevelLoaderWidget
2. Select Run Editor Utility Widget
3. Copy and paste the full file path (on the editable text box above save level button) where you want the .level file you want to be saved (Remove quotation marks if there are any)
4. Press Save Level
